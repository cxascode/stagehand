stagehand

Admin browser extension for Genesys Cloud — extra tools for the features you use, like export to CSV. Uses the session you already have; no OAuth setup required.

Features

  • Historical audit search — query up to one year of audit history from Audit Viewer, with automatic date-range chunking
  • Export to CSV — download results from the extension popup
  • Context-aware — tools appear when you open the matching Genesys Cloud admin page

Install

Chrome / Edge / Brave

Install from the Chrome Web Store. To build from source, see GitHub.

Firefox

Install from Firefox Add-ons. To build from source, see GitHub.

Usage

  1. Log into Genesys Cloud admin in your browser as usual
  2. Open a page that has a stagehand tool (e.g. Audit Viewer)
  3. Click the stagehand icon in the toolbar
